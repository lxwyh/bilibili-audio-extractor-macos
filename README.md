# 视频字幕音频提取器

一个完全在本机运行的 macOS 小工具。粘贴 Bilibili 或抖音视频链接（抖音分享文本也可以），工具会优先获取平台现成字幕并整理为 TXT/SRT；没有字幕时，只保存尽可能低流量的音频。

当前版本：1.1.0。

## 支持的平台

- Bilibili：`bilibili.com`、`b23.tv`
- 抖音：`douyin.com`、`v.douyin.com`，也支持直接粘贴包含链接的分享文本

## 工作方式

1. 自动模式先请求平台已有字幕，不下载视频。
2. 找到字幕后，输出 `完整逐字稿.txt`、`带时间戳字幕.srt` 和原始字幕文件。
3. 没有字幕时，Bilibili 直接下载最低码率独立音频。
4. 抖音优先下载独立音频；如果该视频只提供音视频合一格式，则下载最低质量的带音频文件，再使用 macOS 原生 AVFoundation 在本机剥离为 M4A，临时视频不会保留。
5. “仅提取字幕”模式找不到字幕就停止，不下载媒体文件。

> 抖音的访问策略变化较频繁，通常需要新鲜 Cookie。先在 Chrome、Safari、Firefox 或 Edge 中打开目标视频，再在应用“登录状态”中选择同一浏览器，成功率更高。

## 使用

1. 双击 `视频字幕音频提取器.app`。
2. 粘贴视频链接；抖音可以直接粘贴类似“复制此链接，打开抖音……”的完整分享文本。
3. 选择“自动”“仅字幕”或“仅低码率音频”。
4. 选择保存目录并开始提取。
5. 若内容需要登录或出现风控，先在浏览器确认视频能播放，再选择该浏览器的登录状态重试。

输入框支持标准 macOS `⌘C`、`⌘V`、`⌘X`、`⌘A`、撤销和重做。

## 流量说明

- 检查字幕和元数据只产生少量网络请求。
- Bilibili 通常能直接提供独立音频流。
- 抖音不保证提供独立音频流；回退方案会下载最低质量、包含音轨的媒体文件，因此流量会高于纯音频，但明显低于下载默认清晰度视频。
- 音轨剥离完全在本机进行，不会把视频上传到第三方服务器。

## 从源码构建

要求：Apple Silicon Mac、macOS 13 或更高版本，以及 Apple Command Line Tools。

```bash
chmod +x build.sh
./build.sh
```

构建脚本会在缺失时从 yt-dlp 官方 GitHub Releases 下载通用 macOS 可执行文件，然后生成：

```text
dist/视频字幕音频提取器.app
dist/视频字幕音频提取器.zip
dist/使用说明.md
```

构建产物采用本地 ad-hoc 签名，没有 Apple Developer ID 公证。

## 项目结构

- `App.swift`：原生 AppKit 界面、平台识别、提取流程、字幕清洗与本地音轨剥离。
- `Info.plist`：macOS 应用元数据。
- `make_icon.swift`：应用图标生成器。
- `build.sh`：依赖下载、编译、签名与打包。
- `tests/`：链接识别、字幕解析和提取流程测试素材。
- `THIRD_PARTY_NOTICES.md`：第三方组件声明。

## 注意

- 应用内置 yt-dlp，不需要 Homebrew、Python 或 FFmpeg。
- 最低支持 macOS 13，当前构建目标为 Apple Silicon。
- 浏览器 Cookie 仅由本机 yt-dlp 读取，本应用不会保存或上传 Cookie。
- 不绕过付费、DRM、私密内容或其他访问限制；只处理你有权访问和使用的内容。
